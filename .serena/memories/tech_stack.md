# Tech stack

- Cloudflare Worker in TypeScript (strict, `noUncheckedIndexedAccess`), no bundler step of our own: wrangler builds it. Config: `wrangler.jsonc`.
- **pnpm** (version in `packageManager`), Node >= 24 (`engines`).
- Tests: vitest with `@cloudflare/vitest-plugin`; test secrets are random per run, so no secret-looking literals in the repo.
- Page: no build, no framework; MapLibre from unpkg with integrity hashes.
- Data scripts: Node `.mjs`; PLATEAU conversion in Python standard library only.
- `worker-configuration.d.ts` is generated by `wrangler types` and git-ignored.

Serena: `typescript` language server.
